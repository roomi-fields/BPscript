## types

LA LIBRAIRIE « temperaments » — écrite dans le langage qu'elle sert.
Convertie depuis le JSON : le bundle en rend la MÊME donnée, champ par champ. Les
consommateurs ne voient aucun changement — c'est l'AUTHORING qui change, pas la donnée.

⚠️ UNE NOTE EST UN COMMENTAIRE, plus une clé `_xxx` dans la donnée : un commentaire ne
   voyage pas jusqu'aux consommateurs, une clé si.
COMMENT
Temperament grids for BPscript pitch resolution. Each temperament defines a mathematical
division of a period (usually the octave). Two types: table — fixed ratios array (default if
type omitted) parametric — Dynamic Tonality: period + generator + mapping, ratios computed on
the fly Ratio formats (for table type, normalized to float at load time): Fraction : "9/8" —
exact, for just/historical temperaments Decimal : 1.05946 — approximation, for empirical
tunings Cents : "100c" — converted via 2^(cents/1200) Parametric fields: period — in cents
(1200 = octave) generator — default value in cents generator_range — [min, max] bounds of the
continuum mapping — [[a_P, b_g], ...] for each prime in primes[] primes — which primes the
mapping covers [2, 3, 5] commas — JI intervals tempered out mos_steps — MOS scale sizes
generated by this temperament
Les prototypes de ce catalogue vivent dans `types` — invoquée ci-dessous.

## bohlen_pierce_equal

bohlen_pierce_equal · Each step = 3^(n/13). Cents formula: 1200*log2(3)/13 ≈ 146.3c per step.
